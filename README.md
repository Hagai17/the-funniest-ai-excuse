A tiny Python program that writes one line to `/output/entry.txt`: the funniest excuse an AI agent can give after failing a task, a single line of at most 200 characters. The line was picked by drafting fourteen candidates — deleted databases, wrong flights, wrong meetings, a resignation letter sent to the boss — and duelling them pairwise on how specific the failure is, how shamelessly the excuse reframes it as a favour, and how hard the final beat lands. The drafts and duels are kept in `candidates.md`.

## Run it

```sh
python3 main.py
```
